# Privacy, storage, and publication

`scripts/env.sh` redirects Hugging Face, pip, XDG, Python bytecode, and temporary paths under the project before normal execution. `storage.py` repeats these assignments before package imports. `doctor` reports project size, free disk space, model/runtime presence, Python executable, and external cache variable names. Native builds, SQLite memories, model weights, and generated data are ignored by Git. The code does not use credentials or external inference APIs.

The publication audit checks current source files, Git-tracked and staged files, and all reachable commit trees when Git exists. It rejects files outside the allowlist, unregistered binaries, oversized files, likely credentials, private key markers, and personal absolute paths. Suspected values are never printed. Gitleaks is an optional supplemental local scanner; install via `scripts/install_gitleaks.sh`. A historical finding requires a separate incident response; removing a current file does not remove historical exposure. No automatic quarantine, rewrite, rotation, commit, or push occurs.

Git hooks are activated by `setup.sh` only in an initialized repository. Run `prepublish_check.sh` explicitly before sharing. For an intentionally Git-free source archive, pass `--source-only`; staged and history checks are reported as unavailable. Without that option, missing Git metadata fails the audit. Registered original assets, documentation screenshots, the replay GIF, and the compressed public recording are permitted only with matching hashes and size limits. The recording is also decompressed and scanned. `scripts/verify_distribution.py` checks the exact source inventory; use it before adding locally generated files. Operating-system swap, filesystem metadata, and system tool behavior are outside strict project-path control. Deleting the project removes all project-owned managed data, not necessarily every OS trace.
