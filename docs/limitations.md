# Limitations

The model is two-dimensional and has dimensionless ticks, no measured body size, hydrodynamics, occlusion, predator satiation, or species-specific sensory response. Food is point-like and replenishment is simplified. Prey move in fixed identity order within a tick, so earlier agents can affect later steering and win contested food; this scheduling bias should be tested against randomized or simultaneous updates before strong collective-behavior claims. Wall collision creates an instantaneous velocity change. The predator uses finite-range pursuit and seeded patrol, not a measured hunting strategy. A prey's LFM3 objective is held for a short duration, but steering is entirely mechanistic. Fixed social weights and baseline rules are engineering assumptions.

The 2002 Couzin paper discusses group-level collective memory in movement dynamics. Here, condition C's SQLite history is **individual external memory**, a different construct. No model weights change, and neither adaptation nor emergent intelligence has been demonstrated. D's scrambled memory preserves record shape but does not guarantee equal token count or equal semantic distraction. B receives no persistent records but retains within-episode physical and scheduling state. These distinctions limit attribution.

Calibration used only mechanistic agents and a finite grid. The selected configuration avoids the original ten-tick survival ceiling but may not remain balanced under other group sizes or LFM3 policies. Short real-model runs with few seeds or ticks cannot establish treatment effects. Bootstrap intervals at five or more seeds describe only the simulator's random-seed variation. There is no empirical fish dataset, external validation, or statistical power analysis. Longer real-model evaluation has a material inference-time and memory cost and should be budgeted explicitly.

The operating system may write swap and metadata outside the project. The application's managed weights, caches, databases, and results remain project-local. Publication checks cannot inspect a remote history when no remote is configured. Confirm licensing of newly authored code before public release.
